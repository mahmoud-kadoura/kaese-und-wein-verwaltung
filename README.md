# Käse- und Weinverwaltung

Java-Konsolenanwendung zur Verwaltung von Käse- und Weinprodukten.

## Funktionen

- Benutzerregistrierung
- Benutzeranmeldung
- Produkte hinzufügen
- Produkte löschen
- Produktsuche
- Lagerstatistik
- Historie
- Automatische Entsorgung
- Tages-Simulation

## Verwendete Technologien

- Java
- OOP
- Vererbung
- Polymorphismus
- ArrayList
- LocalDate
- LocalDateTime
